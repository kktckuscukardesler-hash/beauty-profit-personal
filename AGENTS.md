# Beauty Profit — общие правила для ИИ-помощников

Над проектом работают два человека с разными ИИ:
- одна участница — через **Claude Code**,
- другая (Оля) — через **ChatGPT / Codex**.

Оба ИИ читают этот файл. Соблюдайте эти правила, чтобы не мешать друг другу.

## О проекте
- Beauty Profit — веб-приложение для мастеров красоты: себестоимость услуг,
  рекомендуемая цена, клиенты, записи, доходы, напоминания.
- Сайт: https://sprightly-kelpie-11cca6.netlify.app/ (Netlify).
- Весь сайт — один статический файл `index.html` (Vue 3 встроен в файл, без сборки).
  - Экраны переключаются через `view` (`landing`, `auth`, `signupSteps`, `onboard`, `app` и др.).
  - Вкладки кабинета переключаются через `tab` (`dash`, `calc`, `svcs`, `appts`, `income`, `remind`).
  - Supabase подключается через `window.BPC_CONFIG` (`SUPABASE_URL`, `SUPABASE_ANON_KEY`).
- `registration-preview.html` — копия `index.html`, которая сразу открывает шаги
  регистрации (для предпросмотра). Отличается от `index.html` только стартовым экраном.
  Если меняете общий код, меняйте его в обоих файлах.

## Правила работы
1. **Не создавать новый сайт и не переписывать проект с нуля.** Сохранять текущий
   дизайн (цвета, шрифты Cormorant Garamond + Lato, вёрстку) и весь существующий функционал.
2. **Не коммитить напрямую в `main`.** `main` — это рабочая версия сайта.
3. Каждое изменение — в **отдельной ветке**, затем **Pull Request** в `main` для согласования.
   - Ветки Claude: `claude/...`
   - Ветки GPT/Codex: `codex/...` или `gpt/...`
4. **Перед началом работы забирать свежий `main`**, чтобы не затереть чужие правки.
5. Не править одно и то же место одновременно: договариваться, кто какой экран или раздел делает.
6. **Никаких секретных ключей в коде** (OpenAI API key, Supabase service_role key и т. п.).
   В `index.html` допустим только публичный `SUPABASE_ANON_KEY`. Секреты — в Supabase
   Secrets / Edge Functions или в переменных окружения Netlify.
7. Небольшие, понятные изменения. В описании Pull Request коротко объяснять **на русском**,
   что изменено и как это проверить.
8. Интерфейс сайта — на русском языке.
